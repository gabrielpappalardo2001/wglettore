# Sicurezza

Il codice di WGLettore è pubblico: la sicurezza non dipende dal fatto che il codice sia segreto.

- La chiave privata con cui si firmano i rilasci resta sul computer di chi pubblica. Nel codice c'è solo la chiave pubblica: un rilascio con la firma sbagliata non si installa, da qualunque parte arrivi.
- Nel repository non ci sono password, chiavi o token.

Se trovi una vulnerabilità, non aprire una segnalazione pubblica: usa «Report a vulnerability» nella scheda Security di questo repository.
